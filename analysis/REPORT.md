# BTC/ETH 每週 DCA「星期幾買」EV 多角度驗證與壓力測試

**日期**：2026-07-03　**分析者**：Claude Code　**資料截止**：2026-05-24

> **一句話結論**：全歷史(2010s)確實存在「週一/週二便宜、週末貴」的效應,但它是**牛市 + 高波動 regime 特有**、集中在 2020–21 散戶狂熱期的現象;**近三年(2023+)這個效應在 BTC、ETH 以及另外 6 個幣上全部消失**,近三年的日間價差比純隨機漫步(GBM)還小(落在雜訊分佈第 14–30 百分位)。就算拿全歷史數字當真,能撈到的價差扣掉手續費+滑點後 ≈ 0.1–0.5%,而且「最便宜是哪天」對時區、週定義、價格慣例、指標選擇全都不穩定(BTC 的兩種合法指標排名相關係數是 **−0.21 ~ −0.61**)。**現在**每週 DCA,選哪天沒有實質、扣成本後仍存在、跨參數穩健的 EV 差異。不值得寫進機械化規則。

## 0. 資料存取誠實聲明(最重要,先講)

這個 sandbox 的對外網路被組織 egress policy 嚴格限制。我逐一實測,結果如下:

| 目標 | 結果 |
|---|---|
| `api.binance.com`, `api.exchange.coinbase.com`, `api.bybit.com`, `api.kraken.com`, `min-api.cryptocompare.com`, `api.coingecko.com` | **全部 403 政策拒絕**(host_not_allowed) |
| `data.binance.vision`(Binance 官方歷史 dump) | **403**(curl 與 WebFetch 皆然) |
| `api.github.com`、`github.com/.../raw` | **403** |
| Git LFS media(外部 repo) | **Not authorized**(只授權本 session 綁定的 repo) |
| `raw.githubusercontent.com`、`git clone` 公開 repo、WebSearch | ✅ 可用 |

**結論:唯一能拿到真實資料的通道是 GitHub(git clone / raw)。** 所有交易所 API、Binance 官方 dump、以及所有「每日更新」但用 LFS 存的近期高頻資料都打不到。我**沒有用任何合成資料冒充真實結果**;所有數字都來自下列已驗證為真的公開檔案。凡是替代方案我都記錄在下面。

**因應被擋而採取的替代路徑(逐一交代)**:
1. 交易所 API 全擋 → 改用公開 GitHub repo 內**已 commit 的真實 OHLCV CSV**(git clone)。
2. `data.binance.vision` + LFS 全擋 → **近期(2023+)真實日內資料拿不到**。市面上找得到的近期 plain 1h 檔全是 ~1000 列(≈41 天)的 API 快照,週數太少無法做「星期幾」統計(至少要 ~50 週)。因此:
   - **時區(UTC vs Asia/Taipei)修正**——只有日內資料做得到——是在 **2013–2019 真實交易所日內資料**上做的(這剛好是效應最強的早期,是最該檢驗的窗口)。
   - **「近三年是否仍存在」**只能用 CoinMetrics **每日**參考價(UTC 日界)驗,無法在近期做時區修正。這一點如實標明,不硬凹。
3. 跨資產(K)原本點名 SOL,但這份 CoinMetrics community dump 裡 `sol.csv` 的價格欄幾乎全空(2235 列只有 7 個非空)→ 改用 **BNB + ADA + XRP + LTC + DOGE** 5 個有完整價格的幣。
4. Placebo(F)GBM 用**全樣本單一 σ**(未建模波動叢集),這會讓真實價差看起來略「不極端」——屬保守簡化,已註明。

## 2. 三指標一致性(A + B)

對每份資料同時算三種「哪天便宜」指標:**(i) 週內比值法**(當天/當週均價,題目主方法)、**(ii) 每日 log-return 均值法**、**(iii) $1 週定額調和成本法(先做 90 日移動平均去趨勢)**,比較排名。

**結論:三指標排名經常不一致,尤其 BTC。** 用 Spearman 量化「比值法 vs 調和法」排名相關:

| 資料 | Spearman(ratio, harmonic) | 解讀 |
|---|---|---|
| BTC 每日 全歷史 | **−0.21** | 幾乎不相關(略反向) |
| BTC 每日 近3年 | +0.00 | 完全不相關 |
| BTC 日內 全歷史 | **−0.61** | **強烈反向**——兩個合法指標選出相反的「最便宜日」 |
| ETH 每日 全歷史 | +0.43 | 中等一致 |
| ETH 每日 近3年 | +0.93 | 一致(但兩者都不顯著,見下) |

具體例子(BTC 全歷史):比值法排 `Mon<Tue<…<Sun`(週一最便宜、週日最貴),但去趨勢調和法排 `Sun<Mon<Sat<…<Wed`(**週日最便宜**)。**同一份資料、兩個都算「合理」的指標,選出的最便宜日正好相反。** 這本身就說明 BTC 的「最便宜日」不是穩定訊號,而是隨方法漂移的雜訊。唯一三指標都同意的是 **ETH 全歷史 = 週二最便宜**。

**重點解讀(驗收 1、2、3)**:

- **全歷史顯著 ≠ 現在有效**:BTC/ETH 每日全歷史三線全顯著;**近三年三線全部不顯著**(BTC perm 0.73、ETH perm 0.92)。這是核心發現,延續並確認了前一輪。
- **三方法會互相矛盾,如實列出**:
  - BTC 近1年:ANOVA/KW 顯著但 **permutation 不顯著(0.065)**,而且只有 53 週、最便宜日反轉成 Sat——正是小樣本不穩定(陷阱 4),不足採信。

  - 全歷史:最貴日 **Sun → Wed**(Spearman 排名相關僅 0.59);
  - 2013–15:最便宜 **Sat → Sun**、最貴 **Tue → Wed**(Spearman **僅 0.11**,兩種日界排名幾乎無關);
  - 也就是說「星期幾便宜」的答案會被你用哪個時區切日界左右,早期尤其嚴重。**這是 daily 資料做不到、必須用日內資料才驗得出來的修正**,前一輪只用 UTC 因而看不到。

## 5. Placebo 基準(F)+ walk-forward 樣本外命中率(G)

### F. Placebo:同長度、同波動 GBM(結構上不可能有星期幾效應)跑同一 pipeline,各 200 次

| 資料 | σ(年化) | 觀察價差% | 雜訊中位數% | 雜訊 p95% | **觀察值落在雜訊分佈第幾百分位** |
|---|---:|---:|---:|---:|---:|
| BTC 全歷史 | 0.90 | 1.198 | 0.740 | 1.347 | **88**(顯著但**未破雜訊 p95**) |
| **BTC 近3年** | 0.46 | 0.444 | 0.568 | 1.054 | **30**(**比雜訊中位數還小**) |
| ETH 全歷史 | 1.02 | 1.078 | 1.006 | 1.696 | **55**(幾乎就在雜訊中位數上) |
| **ETH 近3年** | 0.65 | 0.501 | 0.797 | 1.564 | **14**(**遠低於雜訊**) |

**這是最客觀的一刀(驗收 4)**:
- 近三年 BTC(0.444%)/ETH(0.501%)的價差,**連純隨機漫步都輕鬆超過**——落在雜訊分佈第 30 / 14 百分位。所以答案很直接:**近三年那個 ~0.45–0.50% 的價差,隨機雜訊不但達得到,而且通常還更大。這不是訊號。**
- 即使全歷史「三線都 p<1e-6」的 BTC 1.198%,也只到雜訊第 88 百分位(沒破 p95);ETH 1.078% 更只在第 55 百分位。**全歷史的顯著性主要來自樣本大(828 週)而非效應強**——效應量相對於幣價本身的隨機波動並不大。
- 註:permutation 與 GBM 是兩種不同虛無。permutation(打亂日標籤)對 BTC 全歷史 p≈0,說明「日標籤確實帶了一點真實結構」;GBM 說明「這結構的量級相對一般價格雜訊並不大」。兩者都對,綜合就是:**全歷史有微弱但真實的日結構,量級不大,近期消失。**

| 資產 | 樣本外次數 | 命中率(選出的最便宜日,樣本外真的贏過當週均價的比例) |
|---|---:|---:|
| BTC | 29 | **0.655** |
| ETH | 19 | **0.526**(≈擲硬幣) |

BTC 65.5% 略高於硬幣但樣本僅 29 次、且 ETH 幾乎就是 50%。**跨資產不一致 → 不是可靠的可交易規則。** 這比單次 60/40 切分更誠實地回答「拿來用有多少把握」:大概就是硬幣多一點點,ETH 連這點都沒有。

## 6. 成本調整後結論(H)

DCA 頻率不變(一週一筆),重點不是省手續費次數,而是**價差有沒有大過你實際會吃到的價差/滑點**。實務執行成本(現貨 taker):Binance 0.10%(BNB 抵扣 0.075%)、Coinbase Advanced ~0.05–0.6%、主流幣 bid-ask/滑點 ~0.02%。

一個 DCA 買家最多只能撈到「當週均價 − 最便宜日」≈ 最大-最小價差的**一半**,且前提是**事先就知道哪天最便宜**(§4、§5 已證明你不知道):

| 情境 | 最大-最小價差% | 樂觀可撈(≈半價差)% | 扣 taker+滑點後淨% |
|---|---:|---:|---:|
| BTC 全歷史 | 1.198 | 0.599 | **0.479** |
| **BTC 近3年** | 0.444 | 0.222 | **0.102** |
| ETH 全歷史 | 1.078 | 0.539 | 0.419 |
| **ETH 近3年** | 0.501 | 0.251 | **0.131** |
| 真實日內 BTC 2013–19 | 0.797 | 0.399 | 0.278 |

**近三年扣成本後淨值 ≈ 0.10–0.13%**,而 §5 已證明這個價差**本身就落在雜訊裡(小於隨機漫步中位數)**——所以這 0.1% 不是「小但真」,而是**統計上與 0 無異、且事前不可知**。結論:**扣成本後不剩任何可靠 EV。**

## 7. 敏感度分析(I + J + L):結論對參數有多脆弱

| 面向 | 測試 | 結果 | 穩健? |
|---|---|---|---|
| **I. 週定義** | ISO 週 vs 滾動 7 天 | BTC 全歷史最便宜日 **Mon(ISO)→ Sun(roll7)**,價差 1.20→1.64%;ETH 最便宜 Tue→Sat | ❌ **不穩健**(排名翻轉) |
| **I. Permutation 次數** | 2000 vs 5000 | BTC 全 0.0005→0.0002;BTC 近3年 0.753→0.749 | ✅ 穩健(p 值收斂) |
| **J. 價格慣例** | close / open / vwap(日內) | 方向(Mon 便宜)一致,但**顯著性大不同**:close 不顯著(perm 0.88)、**open 顯著(perm 0.049 UTC / 0.010 Taipei)**、vwap 介於中間 | ⚠️ **量級/顯著性強烈依賴慣例** |
| **L. K線粒度** | 1H / 4H / daily bars → 日收盤 | UTC 下三者**完全相同**(0.571%);唯 Taipei 下 daily-bar 退化成 UTC(日 bar 無日內解析度,無法重切台灣日界——正好證明時區修正非要日內不可) | ✅ 方向不因取樣頻率反轉 |

**綜合:結論對「怎麼定義一週」和「用開盤還收盤價」很脆弱**(週定義會翻轉最便宜日;open 顯著而 close 不顯著),對「permutation 次數」和「K線粒度」則穩健。一個真實、可交易的曆法效應,不應該換個週定義或改用開盤價就翻盤——這種脆弱性本身就是「這不是穩健訊號」的證據(驗收 9)。

## 9. 總結論

**問題:現在(不是十年前)每週 DCA 買 BTC/ETH,選哪天有沒有實質、扣成本後仍存在、跨參數與跨粒度穩健的 EV 差異?**

**答案:沒有。**

1. **全歷史 vs 近期(驗收 1)**:全歷史(2010s)有真效應——BTC/ETH/BNB 週一/週二便宜、週末貴,三線顯著。但**近三年 BTC、ETH 及另外 6 個幣全部三線不顯著**,且近期價差比純隨機漫步還小(F:第 14–30 百分位)。效應已衰減成雜訊。
2. **本質是 regime,不是曆法(E/M)**:效應集中在**牛市 + 高波動 + 2020–21 散戶狂熱**期,熊市/機構化/ETF 時代不存在。隨市場成熟(機構套利、24/7 深流動性)而消失,符合「早期薄流動性造成、成熟後被套利掉」的假說。
3. **就算當真也撈不到(H)**:近三年扣成本後淨 EV ≈ 0.1%,且統計上與 0 無異、事前不可知。
4. **不穩健(I/J/D/§2)**:最便宜日對時區(Spearman 低到 0.11)、週定義(Mon↔Sun 翻轉)、價格慣例(open 顯著/close 不顯著)、指標選擇(BTC ratio vs harmonic 排名相關 −0.21~−0.61)全都敏感,52 週滾動下漂遍 7 天。
5. **給實務的一句話(驗收 5)**:**不要把「星期幾」寫進 DCA 機械化規則。** 現在每週固定挑一天買,長期 EV 與隨機挑一天沒有可靠差別,省下的 <0.1% 還會被手續費/滑點吃掉。若真要優化 DCA,分散進場點(例如一週拆數筆)降低單點時機風險,遠比賭「星期幾」實在。唯一有資料支持的微弱傾向:**若硬要選,牛市+高波動期偏向週一/週二買、避開週末**;但這在平靜/熊市期無效,近三年整體無效。
